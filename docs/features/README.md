# Features

One folder per feature, named `F-xx-short-name`, holding:

- `spec.md` – what and why, acceptance criteria ([template](_templates/spec.md)), written by `/spec`,
- `plan.md` – ordered steps with their tests ([template](_templates/plan.md)), written by `/plan-feature`,
- `review.md` – findings and resolutions ([template](_templates/review.md)), written by `/review-branch`.

These files are the memory of the project: a new session starts from them, not from chat history. See [../workflow.md](../workflow.md).
