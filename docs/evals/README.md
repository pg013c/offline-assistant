# Evaluation results

Published results of evaluation runs (`make eval`). The cases and configuration live in the top-level `evals/` folder (created in F-04); this folder holds the outcomes that set a baseline or compare models.

One file per run that changes a baseline: `YYYY-MM-DD-<topic>.md`, with model versions, hardware, configuration, metrics and a short interpretation.
